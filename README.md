# zero-to-tech

一个从零开始学习 Web 全栈开发的练习项目。

## 项目简介

本项目用于记录和实践 Web 开发基础知识，通过编写 HTML、CSS 和 JavaScript，逐步掌握网页开发的基本流程。

## 技术栈

- HTML：网页结构
- CSS：网页样式
- JavaScript：网页交互
- Git：版本控制
- GitHub：代码托管

## 项目结构

```text
zero-to-tech/
├── index.html
├── style.css
└── README.md
```

## 当前功能

- 基础网页布局
- CSS 样式设计
- Flex 弹性布局
- JavaScript 点击事件
- DOM 元素操作

## 如何运行

1. 克隆项目：

   ```bash
   git clone https://github.com/wdqfdw/zero-to-tech.git
   ```

2. 进入项目目录：

   ```bash
   cd zero-to-tech
   ```

3. 使用浏览器打开 `index.html`。

## 学习目标

- 掌握前端开发基础
- 学习 React 和 Next.js
- 学习 Python 和 FastAPI
- 掌握数据库基础
- 学习 Linux 服务器部署
- 逐步具备独立开发 AI Agent 应用的能力
